Freelancer Job Dataset – Data Dictionary
Field	Data Type	Description
email_id	String	Unique identifier assigned to the email
email_date	DateTime	Date and time the email was received
sender	String	Email sender
subject	String	Email subject
platform	String	Platform from which job notification originated
job_title	String	Title of the freelance project
job_description	Text	Full or cleaned description of the job
skills	Text/List	Skills requested by the client
